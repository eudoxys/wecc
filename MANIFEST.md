# MANIFEST

Map of the `eudoxys/wecc` repository. Every tracked file is covered by
one row or glob below; check with `python .github/check_manifest.py`.
Update this file in the same PR that adds, moves, or deletes a file.

## Start here

1. `CLAUDE.md` — conventions and working rules
2. `DESIGN.md` — agreed design, decisions, planned modules
3. `wecc/__init__.py` — package docs and public API
4. `wecc/<core>.py` — the core model

## Task index

- Add a data source/class: copy `wecc/<similar>.py`; export in `wecc/__init__.py`; test in `wecc/_test/test_<name>.py`; add rows here
- Change an output column: module docstring example, `wecc/__init__.py` Data section, `README.md`, `DESIGN.md` columns table
- Add or refresh weather data: `wecc weather STATE YEAR [--refresh]` (`wecc/weather.py`)
- Add a CLI option: `wecc/cli.py`, `wecc/__init__.py` Syntax section
- Regenerate curated data: script named in the data table below; update that folder's `README.md`
- Release: `pyproject.toml` version; see the eudoxys-package skill checklist

## WECC estimate scripts

Copies of the `eudoxys/loads` maintenance scripts in `loads/wecc/` that
produced the WECC data below. Run from the folder
(`python3 wecc/<script>.py`); they are not importable modules and have no
tests.

| Path | Purpose | Notes |
|---|---|---|
| `wecc/wecc_estimate.py` | hourly 2018–2022 calibrated load of every WECC county | hours on an empty cache; writes `wecc_estimate.csv.gz` |
| `wecc/node_estimate.py` | WECC240 node loads from the county estimates | writes `node_estimate.csv.gz`, `node_estimate_cf.csv` |
| `wecc/county_dg_scale.py` | scales county PV to EIA small-scale solar | writes `county_dg_scaled.csv.gz`, `county_dg_scaling.csv` |

## Data

All data is checked in under `wecc/` (about 18.4 GB in 14,170 files, almost
all of it in `wecc/loads/`). Sizes are as checked in. None of it is listed in
`pyproject.toml` package-data, so it ships with a clone but not with
`pip install`. Don't read files over ~1 MB; use `head` or
`pandas.read_csv(..., nrows=5)`.

### WECC tables (`wecc/`)

Hourly data are indexed by a UTC `timestamp`; county columns are named
`County ST`.

| Path | Purpose | Notes |
|---|---|---|
| `wecc/clusters.csv` | county → cluster medoid (`county_st,medoid`) | curated; copy of `loads/clusters.csv`; read by `wecc/loads.py`, `wecc_estimate.py` |
| `wecc/county_mwh.csv` | monthly EIA 861M retail MWh allocated to each county | generated by `python3 -m loads.energy`; 0.4 MB |
| `wecc/county_cf.csv` | county share of state monthly energy | generated by `python3 -m loads.energy`; 0.4 MB |
| `wecc/county_dg.csv` | hourly county rooftop PV (MW, positive) 2018–2022 | generated from `dgen.csv.gz`; 82 MB, don't read |
| `wecc/county_dg.csv.gz` | compressed copy of `county_dg.csv` | read by `wecc_estimate.py`; 18 MB, don't read |
| `wecc/county_dg_scaled.csv.gz` | county PV scaled to EIA small-scale PV by state and year (MW, positive) | generated by `county_dg_scale.py`; 22 MB, don't read |
| `wecc/county_dg_scaling.csv` | state × year PV scale factors | generated by `county_dg_scale.py` |
| `wecc/dgen.csv.gz` | NREL dGen nodal DG | source of `county_dg.csv`; 13 MB, don't read |
| `wecc/eia_smallscale_pv.csv` | EIA small-scale PV GWh by state, 2018–2022 | curated; input to `county_dg_scale.py` |
| `wecc/wecc_estimate.csv.gz` | hourly calibrated gross load of the 407 WECC counties, 2018–2022 (MW) | generated by `wecc_estimate.py`; 65 MB, don't read |
| `wecc/node_estimate.csv.gz` | hourly WECC240 node load, 2018–2022 (MW, uncalibrated) | generated by `node_estimate.py`; 21 MB, don't read |
| `wecc/node_estimate_cf.csv` | county → node contribution factors (`county_st,node,cf,method`) | generated by `node_estimate.py` |

### County weather (`wecc/weather/`)

`ST` is a WECC state, `COUNTY` the `fips` county name with spaces replaced by
underscores. Every county of the 13 WECC states is covered, including those
outside WECC.

| Path | Purpose | Notes |
|---|---|---|
| `wecc/weather/*/*/W_*.csv.gz` | `ST/COUNTY/W_YYYY.csv.gz`: hourly NSRDB weather of a county and year | generated by `wecc weather ST YYYY`; 3,678 files, 317 MB (~85 kB each); 2018–2022 for all 734 counties, 2015–2017 and 2023–2025 for a few |
